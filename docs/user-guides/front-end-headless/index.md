# Front-end & Headless

Load Comments from your own JavaScript build, keep the thread working with libraries that swap the page's HTML, and add comments to a headless front end.

## [Bundle Comments in Your Own Build](docs:user-guides/front-end-headless/bundle-comments-in-your-own-build)

Move Comments' script and stylesheet into your site's Vite build, start the thread from your own entry script, and control when it starts. The rich text editor moves into your build too.

## [Comments with Turbo, Sprig or Datastar](docs:user-guides/front-end-headless/comments-with-turbo-sprig-or-datastar)

Keep the right thread on screen when Turbo, Sprig or Datastar swaps or morphs the page, with the one attribute each library needs.

## [Comments on a Headless Site on the Same Domain](docs:user-guides/front-end-headless/comments-on-a-headless-site-on-the-same-domain)

Add the comment thread to a React or Vue app served from the same domain as Craft, with members signing in through their Craft accounts and no keys or tokens to set up.

## [Comments on a Headless Site on Another Domain](docs:user-guides/front-end-headless/comments-on-a-headless-site-on-another-domain)

Add comments to a front end on another subdomain or a different domain from Craft, sharing Craft's session cookie or signing members in with short-lived member tokens.
